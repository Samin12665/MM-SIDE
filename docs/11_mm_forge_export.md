# 11 — MM FORGE Export Package (PHASE 19)

Everything MM FORGE needs is regenerated by one command:

```bash
python3 cad/build.py --check      # parts, assemblies, STEP/STL, volumes, interference + motion report
python3 cad/drawings.py           # drawing views + DRAWINGS.md
python3 bom/generate_bom.py       # BOM / print list / purchase list
xvfb-run -a python3 cad/render.py # renders (needs Xvfb in headless environments)
```

| Deliverable | Path | Notes |
|---|---|---|
| Complete assembly | `out/step/ASM_CAR_COMPLETE.step` | STEP AP214 (OCCT writer). 79 named bodies, one per part/instance, with colours. Vehicle frame, mm |
| Sub-assemblies | `out/step/ASM_{CHASSIS,FRONT_SUSPENSION,REAR_SUSPENSION,STEERING,DRIVETRAIN,SENSOR_SYSTEM,ELECTRONICS}.step` | Same body names as the full assembly |
| Individual parts | `out/step/parts/<NN_NAME>.step` | Custom parts in installed position |
| Printable meshes | `out/stl/<NN_NAME>.stl` | Already in print orientation, on Z = 0 |
| Material assignment | `bom/print_list.csv` (`material`), `out/reports/part_volumes.json` | Density and effective fill, so mass = volume × ρ × fill |
| BOM sync | `bom/BOM.csv` | `item` column = STEP body name for printed parts |
| Wiring planning | `docs/09_…`, SK12 in `CAR_MASTER.fs` | Power right / signal left trunks, pass-through coordinates |
| Interference and motion | `out/reports/interference.md` | 9-state steering × suspension sweep |
| Exploded view | `out/renders/ASM_CAR_COMPLETE_exploded.png`; offsets in `cad/render.py:EXPLODE` | Reuse the offsets for an MM FORGE exploded animation |
| Master parameters | `cad/onshape/car_master_variables.csv` | 123 variables |

Naming convention: `NN_FUNCTION[_SIDE]` for custom parts (NN = subsystem number from the project
hierarchy) and `110_*` for purchased envelopes. L/R suffixes follow the vehicle frame (+Y = left).
Units are mm. The frame is X forward, Y left, Z up, with the origin on the ground plane under the
mid-wheelbase point.

AP242: the OCCT writer produces AP214. If MM FORGE requires AP242 with PMI, import the AP214 file
into Onshape (Path A) and export from Onshape as AP242. Body names and hierarchy are preserved.
